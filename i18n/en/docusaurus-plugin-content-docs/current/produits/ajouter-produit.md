# Add a product

Add products to your project from different sources.

## Adding methods

### From the library

Add products already in your catalogue:

1. In your project, go to the **Products** section
2. Click **Add from library**
3. Use filters to find the desired products
4. Check the products to add
5. Click **Add to project**

Products are added with their full information (price, images, descriptions, etc.).

### Create a new product

Create a product directly in the project:

1. In the project's **Products** section, click **New product**
2. Fill in the product information in the side panel

#### Details tab

- **Name**: Product name (required)
- **Reference**: Internal or manufacturer reference
- **Product type**: Product category(ies) — manage the list in [Product types](/agence/types-produits)
- **Description**: Detailed description
- **Technical note**: Internal notes (never visible to clients; exportable in the booklet and spreadsheet)
- **Manufacturer**: Manufacturer name
- **Supplier**: Supplier name
- **Section**: Project section (room, floor, etc.) — see [Section management](/projet/gestion-sections)
- **Lot**: Associated trade — see [Lot management](/projet/gestion-lots)

#### Supply / install

Visible only when a lot is selected:

- **Supply & install**
- **Install only**
- **Neither supply nor install**

- **Status**: Lifecycle stage (see [Product statuses](/produits/statuts-produits))
- **Delivery tracking** (visible to the client when filled in):
  - Estimated receipt date
  - Tracking link (carrier URL)
  - Tracking number

If a tracking link is present, the **Track package** button opens tracking in a new tab.

#### Finances tab

- **Unit price**
- **Quantity**
- **Unit**
- **VAT**
- **Markup**

3. Add images if needed:
   - Click **Add images**
   - Select files from your computer
   - Drag and drop images or click to browse

4. Click **Save**

### From the Chrome extension

The Chrome extension lets you quickly add products from any website:

1. Install the Chrome extension (see [Extension installation](/extension/installation))
2. Navigate to a website containing a product
3. Click the extension icon
4. The extension automatically extracts product information
5. Review and complete the information if needed
6. Select the destination project
7. Click **Add to project**

See the [extension documentation](/extension/utilisation) for more details.

## View and edit a product

Click a product in the list to open its sheet in a **side panel** on the right. The list remains visible behind it.

The panel offers several tabs:

| Tab | Content |
|-----|---------|
| **Details** | Product info, images, section, lot, tracking |
| **Finances** | Price, quantity, VAT, markup |
| **Chat** | Internal or external discussion around the product |
| **3D** | 3D models (generation or import) |
| **Files** | Documents attached to the product |

## Sync changes across copies

When you save a duplicated product, a **Apply changes to linked products** toggle may appear at the bottom of the form.

Enable it to propagate your changes to all copies linked to this product (from duplication). Disable it to edit only the current sheet.

## Duplicate a product

To create a copy of an existing product:

1. Click the menu (⋮) next to the product, or open the sheet and choose **Duplicate**
2. Select one or **multiple destination sections**
3. Click **Duplicate**

Duplication runs in the background. A notification tells you when the copies are ready.

## Tips

- Use the [catalogue](/catalogue) for recurring products
- Create products in the project for site-specific items
- Use the Chrome extension to quickly extract products from websites
- Always add images to make products easy to identify
