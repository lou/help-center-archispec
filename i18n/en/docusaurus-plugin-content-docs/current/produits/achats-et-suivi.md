# Purchases and tracking

The **Purchases** page groups products being sourced (ordered, in production, shipped, received) and helps you track upcoming deadlines.

## Open purchases

1. In the main navigation, open **Purchases**
2. Filter by status or type (**Client validation** / **Purchase tracking**) if needed

Products are grouped by urgency: **Overdue**, **Today**, **This week**, **Next week**, **Later**.

## Cycle after validation

Once the client has **validated** the product, the agency advances tracking:

| Status | Meaning |
|--------|---------|
| **Ordered** | Order placed with the supplier |
| **In production** | Manufacturing / preparation in progress |
| **In delivery** | Shipped |
| **Received** | Received on site or in storage |
| **Installed** | Installed |

See [Product statuses](/produits/statuts-produits) for the full cycle.

## Enter tracking on a product

1. Open the product sheet
2. Go to the **Tracking** tab (or purchase fields depending on the view)
3. Enter useful dates and details:
   - Order date
   - Production start date
   - Planned / actual shipment
   - Planned / actual receipt
   - Planned / actual installation
   - Carrier tracking number and link

The client can see some delivery information depending on [sharing settings](/projet/parametres-partage).

## Notifications

Enable alerts for purchase deadlines and status changes in [Notifications](/projet/notifications) so you do not miss a delay.
