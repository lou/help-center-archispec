# Price mode

Price mode is an optional feature that displays a detailed price view in the product list.

<VideoPlayer url="https://d3hm1231ux02pa.cloudfront.net/videos/price-mode.mp4" />

## Enable price mode

1. Go to the product list
2. Use the **Price mode** button or toggle in the action bar above the list
3. Price mode activates and shows additional price information

## How it works

Price mode lets you view and analyze your project costs in detail.

### Price display in the list

When Price mode is enabled:

- each product's price is displayed directly in the list
- the total price of all products is visible in the action bar above the list
- the total price of each section is displayed to the right of the corresponding section name

This gives you an immediate view of costs, both globally and by section.

### Price detail and breakdown

Clicking the project total price in the action bar opens a price breakdown screen.
This view lets you analyze amounts by:

- applied filters
- current product selection
- overall project

For each breakdown, you can view:

- margin
- amount excluding tax (excl. tax),
- amount including tax (incl. tax)

This feature is especially useful for refining choices, comparing scenarios, and managing project profitability.

## Disable price mode

To return to the normal view:
1. Click the **Price mode** toggle again in the action bar above the list
2. Price mode deactivates and you return to the standard view

## User preferences
Price mode is remembered. If enabled, it will automatically reactivate on your next visits.
