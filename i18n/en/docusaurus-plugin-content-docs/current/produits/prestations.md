# Services

A **service** is a service line (installation, labor, study, fees) for the client to validate, without a catalog product sheet.

## Difference from a product

| | Product | Service |
|---|---------|---------|
| Use | Furniture, equipment, finish… | Installation, labor, study… |
| Catalog | Can come from the catalog | Project-specific |
| Procurement | Yes (order → installation) | No — validation cycle only |
| Budget | Included | Included (fixed amount or % of envelope) |

## Create a service

1. In the project **Products** list, open the **Add** menu
2. Choose **Service**
3. Enter the **title**, **description**, **area**, **lot**, quantity, and price
4. Choose whether the service is **visible to the client**
5. Save

You can also create a service from the [Budget](/projet/budget) tab.

## Pricing modes

A service can be priced in three ways:

| Mode | Effect |
|------|--------|
| **Fixed amount** | Unit price × quantity |
| **% of project envelope** | Percentage of the global envelope |
| **% of lot envelope** | Percentage of the lot envelope (a lot must be selected) |

Optionally, check **Include in markup** so the amount counts in the budget markup indicator.

:::info
If you change the amount of an already **validated** service, it returns to **Proposed** and the client must validate it again.
:::

## Client validation

Services follow a simple cycle:

1. **Draft** / hidden — agency preparation
2. **Proposed** — presented to the client
3. The client **validates** or **rejects**
4. **Validated** — client agreement recorded

You can set a **validation deadline** on the service, or let the lot deadline apply. See [Validation deadlines](/projet/echeances-validation).

## Show products and services

In the project list, the view options menu lets you:

- Switch to **List** to see prices on each row (see [List mode](/produits/mode-liste))
- Show **Products and services**, **Products only**, or **Services only**
- **Group by** area or lot

## Discussion and files

Like a product, a service has:

- a **discussion** thread (internal and external channels)
- a dedicated **Files** space
