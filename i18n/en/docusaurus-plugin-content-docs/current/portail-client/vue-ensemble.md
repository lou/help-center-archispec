# Client portal overview

Clients invited to a project access a dedicated space, separate from the agency interface.

## Access

1. The client receives an invitation email
2. They click the link and sign in (or create an account)
3. They access their project directly

The client portal URL follows the format `archispec.fr/client/projects/...`.

## Client navigation

The client portal offers the following tabs:

| Tab | Content |
|-----|---------|
| **Products** | Products proposed by the agency |
| **Files** | Documents shared by the agency (if at least one file is visible) |
| **Progress** | Shared planning (if planning is enabled on the project and shared) |
| **Chat** | External channel — communication with the team |

Clients also access their **Account** (profile and notifications) via the menu in the top right.

## What the client sees

### Products

The client only sees products with **Proposed** status or beyond in the lifecycle. Products **hidden from the client** remain invisible.

For each visible product, depending on [sharing settings](/projet/parametres-partage):

- Name, description, and images
- Price (if shared)
- Web link (if shared)
- Delivery tracking (estimated date, tracking number and link, when filled in)

### Files

Only files the agency has made visible (eye icon enabled). View and download only — no adding or editing files. On visible images and PDFs, the client can still place [annotations](/projet/annotations).

### Progress

Visible only if planning is enabled on the project and client sharing is turned on. The client sees tasks marked as visible.

### Chat

The client accesses the **external channel** only. The team's internal channel is inaccessible.

## What the client cannot do

| Action | Available to client |
|--------|:-------------------:|
| Create or edit products | No |
| Export documents | No |
| Generate 3D models | No |
| Access internal chat | No |
| Edit project settings | No |
| Upload files | No |
| Annotate a visible image or PDF | Yes |
| Invite other agency members | No |

## Preview the client space (agency side)

Before inviting a client, use [client preview](/projet/previsualisation-client) to check what they will see.

You can also open the client portal from the **Client preview** icon in the project bar. A banner indicates you are in preview mode and client actions are disabled.
