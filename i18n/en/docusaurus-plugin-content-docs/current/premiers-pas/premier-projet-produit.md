# Create a project and add a product

Create your first project and add a product to start your specification.

## Create a project

1. In the main menu, click **Projects**
2. Click **New project**
3. Enter the project title (e.g. "Dupont Renovation")
4. Confirm creation

You are redirected to the project page.

## Set up areas (recommended)

Areas organize your products by room or floor:

1. Go to project **Settings**
2. Click **Areas**
3. Add your areas (e.g. "Kitchen", "Living room")

See [Area management](/projet/gestion-zones) for more details.

## Add your first product

Choose one of these methods:

### Create a product manually

1. In the **Products** tab, click **New product**
2. Enter at least the product **name**
3. Assign an **area** if you created any
4. Click **Create**

### From the browser extension

1. Install the [Chrome extension](/extension/installation)
2. Navigate to a supplier product page
3. Open the extension and review the extracted information
4. Select your project and click **Add**

### From the catalog

If you already have products in the catalog:

1. Click **Add from library**
2. Select the desired products
3. Click **Add to project**
