# Files

Centralize plans, technical sheets, visuals, and exports in your project's **Files** tab.

## Access files

1. Open your project
2. Click the **Files** tab

You see the folder tree and the list of files in the current folder.

## Add a file

1. In the **Files** tab, click **Add a file**
2. Select the file on your computer
3. Wait for the upload to complete

The file appears in the open folder.

## Create a folder

1. Click **New folder**
2. Enter the folder name
3. Confirm creation

You can navigate subfolders via the breadcrumb at the top of the page.

## Share a file with the client

By default, files are not visible to the client.

1. Find the eye icon to the right of the file
2. Click to toggle visibility:
   - Open eye: the file is visible to the client
   - Crossed-out eye: the file is hidden from the client

:::info
For more details on client sharing, see [Client sharing](/projet/partage-client).
:::

## Annotate an image or PDF

On an image or PDF, open the preview then click the document to place a pinpoint comment. The team and clients can reply in the same thread, resolve the item, or mention someone with `@`.

See [Annotations](/projet/annotations) for details.

## Product files

Each product has its own file space:

1. Open a product
2. Go to the **Files** tab on the product page

Documents attached to a product (technical sheets, visuals, etc.) are grouped in this folder.

## Export folders

When you export products (PDF spec book or Excel spreadsheet), Archispec generates files in dedicated project folders.

1. See [Select products](/produits/selection) to start an export
2. Once generation is complete, find the file in the project **Files** tab

## Client side

Clients invited to the project can view and download only files you have made visible. They cannot add, edit, or delete files. They can, however, [annotate](/projet/annotations) visible images and PDFs.
