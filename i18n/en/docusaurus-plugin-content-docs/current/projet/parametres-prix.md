# Price settings

Configure how prices are displayed in your project.

## Display prices with or without tax

1. Go to project **Settings**
2. Click **Price display** in the sidebar
3. Choose the display option:
   - **With tax**: Displayed prices include tax (incl. tax)
   - **Without tax**: Displayed prices exclude tax (excl. tax)
4. The change is saved automatically

This option determines how prices are displayed throughout the project interface and in the client interface.
