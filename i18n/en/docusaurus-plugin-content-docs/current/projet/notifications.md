# Notifications

Stay informed of important activity in your projects with the notification center and customizable preferences.

## Notification center

1. Click the notifications icon in the navigation bar
2. Review the list of recent events (status changes, messages, etc.)
3. Click a notification to go directly to the related item

## Configure your preferences

1. Go to your account **Settings**
2. Open the **Notification preferences** section
3. For each event type, enable or disable the desired channels:
   - **App**: notification in the notification center
   - **Email**: email delivery

4. Click **Save**

:::info
These preferences apply by default to all your projects. You can change them individually in each project's settings.
:::

## Notifiable events (team)

| Event | Description |
|-------|-------------|
| Status changed by a client | A client changes a product's status (liked, approved, etc.) |
| Status changed by a member | A colleague updates a product's status |
| Message from a member | A team member sends a message in chat |
| Message from a client | A client contacts you via chat |
| Annotations | A comment is added on an annotation, or an annotation is resolved / reopened |
| Mentions | Someone mentions you with `@` (chat or annotation) |

:::info
Annotation notifications go to the team. Clients are alerted when they are mentioned with `@`. See [Annotations](/projet/annotations).
:::

## Best practices

- Enable **email** notifications for client messages if you don't check Archispec continuously
- Enable **app** notifications for day-to-day product approval tracking
- Review your preferences when inviting a new client to a project
