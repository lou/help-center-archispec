# Member management

Manage team members who have access to the project. Each member has a role specific to that project.

## Add a member

1. Go to project **Settings**
2. Click **Members** in the sidebar
3. Click **Invite a new member**
4. Select the agency member who should access the project
5. Choose the role to assign:
   - **Owner**: full project control, can archive the project
   - **Administrator**: manages project settings and members
   - **Member**: works on products, files, and chat
6. Click **Add member**

## Edit a member's permissions

1. Click the dropdown menu to the right of the member
2. Select the new role
3. Changes take effect immediately.


## Roles and permissions (team)

| Permission | Owner | Administrator | Member |
|------------|:-----:|:-------------:|:------:|
| Edit products and files | ✅ | ✅ | ✅ |
| Add new products | ✅ | ✅ | ✅ |
| Use chat | ✅ | ✅ | ✅ |
| Project settings | ✅ | ✅ | ❌ |
| Manage members | ✅ | ✅ | ❌ |
| Transfer ownership | ✅ | ❌ | ❌ |
| Archive project | ✅ | ❌ | ❌ |

Roles are hierarchical: an administrator inherits a member's permissions, and an owner inherits an administrator's permissions.

## Clients

The **Client** role gives access to the project's dedicated space: proposed products, shared files, external chat, and annotations on visible files.

Clients are not added via **Members**: they are invited from the **Client** settings. See [Client sharing](/projet/partage-client).
