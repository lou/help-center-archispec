# Budget

The **Budget** tab tracks how your project envelope is consumed by priced products and [services](/produits/prestations). Totals update as soon as a price changes.

## Open the budget

1. Open your project
2. Click the **Budget** tab

:::info
The **Budget** tab is visible to project **administrators** and **owners**. Associates do not have access.
:::

## Project envelope

Set the amount allocated to the project:

1. In **Budget**, click **Set a project envelope** (or the amount already entered)
2. Enter the amount
3. Confirm

**Estimated final cost** aggregates selected products and services. **Envelope variance** (or **overrun**) compares that cost to the envelope.

You can switch display between **excl. tax** and **incl. tax** with the control at the top right.

## Reading the budget

The gauge and indicators break down the amount:

| Indicator | Meaning |
|-----------|---------|
| **Validated** | Validated by the client |
| **Pending** | Proposed (or liked), awaiting client validation |
| **In preparation** | Drafts still included in the forecast |
| **Markup** | Markup calculated on relevant lines |
| **Selections** / **Variance** | Projected amount, or remaining / overrun vs the envelope |

If expected lines still have no price, a message flags an **incomplete forecast**.

## Budget by area or lot

Under the project envelope, read the budget by **area** or by **lot**:

1. Choose the axis (**Area** or **Lot**)
2. Click a line to open the products and services that make up the total

Envelopes can only be set on **lots** (not on areas). On the lot axis, enter an envelope on a line if needed.

**Watch** alerts flag overruns, poorly allocated lot envelopes, or amounts with no area / no lot.

Distribution charts show each area or lot’s share of the total.

:::tip
You can also set a lot envelope from the **Lots** tab.
:::

## Add a service from the budget

From the **Budget** tab, use **Add a service** to create an installation, labor, or fees line without creating a catalog product. See [Services](/produits/prestations).

## In summary

Budget lets you:

- Set a project envelope and per-lot envelopes
- Track estimated cost, validated amount, and the amount still left to validate in real time
- Spot overruns before the client meeting
- Trace each amount back to the products and services involved
