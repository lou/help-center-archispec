# Managing lots

Lots group products and planning tasks by trade (plumbing, carpentry, electrical, etc.). Each project has its own list of lots.

## Access lots

1. Open your project
2. Go to **Settings**
3. Click **Lots** in the side menu

## Create a lot

1. Click **Add**
2. Enter the lot name
3. Choose the **assignee**:
   - **None** — no assignment
   - **Client** — the lot is handled by the client (available if a client is invited to the project)
   - **Company** — link a [company](/agence/entreprises) from your agency (you can create one on the fly)
4. Confirm creation

## Edit or delete a lot

1. Click the edit icon to the right of the lot
2. Change the name or assignee
3. Save

To delete a lot, open edit then confirm deletion. Linked products lose their lot.

## Import lots from another project

To reuse the list from an existing project:

1. In **Lots**, click **Import**
2. Select the source project
3. Confirm

Lots that already exist (same name) are skipped.

You can also import lots when **creating a new project**.

## Using lots

- On a **product**: assign a lot to organize and filter. When a lot is set, you can specify [supply / installation](/produits/ajouter-produit#supply--installation).
- On **planning**: create tasks from a lot to structure the calendar.
- In **bulk edit**: change the lot on several products via [Select products](/produits/selection).

:::tip
Create your [companies](/agence/entreprises) at the agency level first if you want to assign them as lot assignees.
:::
