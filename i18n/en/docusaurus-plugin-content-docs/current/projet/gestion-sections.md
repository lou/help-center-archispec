# Section management

Sections let you organize your project by rooms, floors, or any other logical division.

## Create a section

1. Go to project **Settings**
2. Click **Sections** in the sidebar
3. Click **Add a section**
4. Enter the section name (e.g. "Ground floor", "Kitchen", "Bedroom 1")
5. Optionally add a description
6. Click **Create**

## Edit a section

1. Go to project **Settings**
2. Click **Sections**
3. Click the section you want to edit
4. Change the name or description
5. Click **Save**

## Reorder sections

You can reorder sections by drag and drop:

1. Go to project **Settings**
2. Click **Sections**
3. Click and hold a section
4. Drag it to the desired position
5. Release to confirm

## Delete a section

1. Go to project **Settings**
2. Click **Sections**
3. Click the **trash icon** to the right of the section
4. Confirm the action

**Warning**: If the section contains products, they will all be unassigned and appear as "No section".
