# Archive a project

Archiving lets you keep a project while removing it from your active project list.

## Archive a project

1. Go to project **Settings**
2. Scroll to the **Actions** section
3. Click **Archive project**
4. Confirm the action in the dialog

The project is immediately archived and removed from your active project list.

## Restore an archived project

1. Go to the [project list](https://archispec.fr/app/projects)
2. Show archived projects if needed
3. Open the archived project
4. Go to project **Settings**
5. In the **Archiving** section, click **Restore project**

The project becomes active again and reappears in your project list.

## Effects of archiving

When a project is archived:

- ✅ All products and files are preserved
- ✅ Chat history is preserved
- ✅ Clients can still access the project
- ❌ The project no longer appears in the active project list
