# Installation de l'extension

L'extension Archispec permet d'extraire rapidement des produits depuis n'importe quel site web et de les ajouter à vos projets.

## Installation

1. Accédez au [Chrome Web Store - Extension Archispec](https://chromewebstore.google.com/detail/archispec/adokjifkncmndmiplmgdbofnpckkojpc)
2. Cliquez sur **Ajouter à Chrome**
3. Confirmez l'installation en cliquant sur **Ajouter l'extension**
4. Cliquez sur l'icône de puzzle dans la barre d'outils
5. Cliquez sur l'icône épingler de l'extension Archispec

🎉 L'extension est maintenant installée et l'icône Archispec apparaît dans la barre d'outils de Chrome.

### Navigateurs supportés

L'extension est disponible pour :
- Google Chrome
- Microsoft Edge
- Brave
- Opera
- Tous les navigateurs basés sur Chromium


### Mettre à jour l'extension

L'extension se met à jour automatiquement si elle est installée depuis le Chrome Web Store.
