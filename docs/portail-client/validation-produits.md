# Valider des produits (côté client)

Le portail client permet à vos clients de donner leur avis sur les produits que vous leur proposez, sans accéder à l'interface complète de l'agence.

## Produits visibles

Un client ne voit que les produits dont le statut est **Proposé** ou ultérieur. Les produits en **Non spécifié** restent invisibles tant que l'agence ne les a pas proposés.

Consultez [Statuts des produits](/comprendre/statuts-produits) pour le cycle complet.

## Actions du client

Sur chaque produit proposé, le client peut :

| Action | Effet |
|--------|-------|
| **J'aime** | Le produit passe au statut **Aimé** |
| **À écarter** | Le produit passe au statut **Écarté** |
| **Valider** | Le produit passe au statut **Validé** |

La validation demande une confirmation avant d'être enregistrée.

Le client peut aussi annuler son choix et remettre un produit au statut **Proposé**.

## Actions réservées à l'agence

Les statuts post-validation sont gérés par l'équipe :

- **Commandé**
- **En cours de livraison**
- **Reçu**
- **Installé**

L'agence met à jour ces statuts au fil de l'avancement du chantier.

## Notifications

L'agence peut être notifiée lorsque :

- Un client modifie le statut d'un produit
- Un client envoie un message dans le chat

Configurez vos préférences dans [Notifications](/projet/notifications).

## Bonnes pratiques côté agence

1. Vérifiez que le produit est complet (images, prix, description) avant de le passer en **Proposé**
2. Utilisez la [prévisualisation client](/projet/previsualisation-client) pour contrôler l'affichage
3. Ajustez les [paramètres de partage](/projet/parametres-partage) (prix, liens) avant l'invitation
4. Répondez rapidement aux validations via le chat externe

## Chat par produit

Chaque produit dispose de son propre fil de discussion. Le client peut poser des questions sur un produit précis sans quitter sa fiche.

Le chat du projet (onglet **Chat**) reste disponible pour les échanges généraux.
