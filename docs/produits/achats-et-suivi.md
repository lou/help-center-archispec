# Achats et suivi

La page **Achats** regroupe les produits en cours d’approvisionnement (commandés, en production, expédiés, reçus) et vous aide à suivre les prochaines échéances.

## Accéder aux achats

1. Dans la navigation principale, ouvrez **Achats**
2. Filtrez par statut ou par type (**Validation client** / **Suivi achats**) si besoin

Les produits sont regroupés par urgence : **En retard**, **Aujourd’hui**, **Cette semaine**, **Semaine prochaine**, **Plus tard**.

## Cycle après validation

Une fois le produit **validé** par le client, l’agence fait avancer le suivi :

| Statut | Signification |
|--------|---------------|
| **Commandé** | Commande passée chez le fournisseur |
| **En production** | Fabrication / préparation en cours |
| **En cours de livraison** | Expédié |
| **Reçu** | Réceptionné sur chantier ou en dépôt |
| **Installé** | Posé / installé |

Consultez [Statuts des produits](/produits/statuts-produits) pour le cycle complet.

## Renseigner le suivi sur un produit

1. Ouvrez la fiche du produit
2. Accédez à l’onglet **Suivi** (ou aux champs d’achat selon la vue)
3. Renseignez les dates et informations utiles :
   - Date de commande
   - Date de mise en production
   - Expédition prévue / réelle
   - Réception prévue / réelle
   - Installation prévue / réelle
   - Numéro et lien de suivi transporteur

Le client peut voir certaines informations de livraison selon les [paramètres de partage](/projet/parametres-partage).

## Notifications

Activez les alertes liées aux échéances d’achat et aux changements de statut dans [Notifications](/projet/notifications) pour ne pas manquer un retard.
