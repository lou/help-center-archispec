# Prestations

Une **prestation** est une ligne de service (pose, main-d’œuvre, étude, honoraires) à faire valider par le client, sans passer par une fiche produit catalogue.

## Différence avec un produit

| | Produit | Prestation |
|---|---------|------------|
| Usage | Mobilier, équipement, finition… | Pose, main-d’œuvre, étude… |
| Catalogue | Peut venir du catalogue | Spécifique au projet |
| Suivi achats | Oui (commande → installation) | Non — cycle de validation uniquement |
| Budget | Inclus | Inclus (montant fixe ou % d’enveloppe) |

## Créer une prestation

1. Dans la liste **Produits** du projet, ouvrez le menu **Ajouter**
2. Choisissez **Prestation**
3. Renseignez l’**intitulé**, la **description**, la **zone**, le **lot**, la quantité et le prix
4. Choisissez si la prestation est **visible pour le client**
5. Enregistrez

Vous pouvez aussi créer une prestation depuis l’onglet [Budget](/projet/budget).

## Modes de prix

Une prestation peut être chiffrée de trois façons :

| Mode | Effet |
|------|--------|
| **Montant fixe** | Prix unitaire × quantité |
| **% de l’enveloppe projet** | Pourcentage de l’enveloppe globale |
| **% de l’enveloppe du lot** | Pourcentage de l’enveloppe du lot (un lot doit être choisi) |

Optionnellement, cochez **Inclure dans la marge** pour que le montant compte dans l’indicateur de marge du budget.

:::info
Si vous modifiez le montant d’une prestation déjà **validée**, elle repasse en **Proposé** et le client doit la valider à nouveau.
:::

## Validation client

Les prestations suivent un cycle simple :

1. **Brouillon** / masquée — préparation côté agence
2. **Proposé** — présentée au client
3. Le client **valide** ou **refuse**
4. **Validé** — accord client enregistré

Vous pouvez fixer une **échéance de validation** sur la prestation, ou laisser l’échéance du lot s’appliquer. Voir [Échéances de validation](/projet/echeances-validation).

## Afficher produits et prestations

Dans la liste du projet, le menu d’affichage permet de :

- Afficher **Produits et prestations**, **Produits uniquement** ou **Prestations uniquement**
- **Regrouper par** zone ou par lot

## Discussion et fichiers

Comme un produit, une prestation dispose :

- d’un fil de **discussion** (canaux interne et externe)
- d’un espace **Fichiers** dédié
