# Bon de commande

Générez un bon de commande PDF à partir de vos produits sélectionnés pour commander auprès de vos fournisseurs.

## Prérequis

- Avoir sélectionné un ou plusieurs produits dans la liste du projet
- Les filtres actifs déterminent quels produits sont inclus dans l'export

Consultez [Sélectionner les produits](/produits/selection) pour la sélection en lot.

## Générer un bon de commande

1. Dans l'onglet **Produits** du projet, sélectionnez les produits à commander
2. Cliquez sur **Exporter** > **Bon de commande**
3. Remplissez le formulaire :
   - **Nom du fichier**
   - **Numéro de bon de commande** (obligatoire)
   - **Date**
   - **Adresse du fournisseur**
   - **Adresse de l'émetteur** (votre agence)
   - **Détails de livraison**
   - **Notes** (optionnel)
   - **Inclure la TVA** (case à cocher)
4. Cliquez sur **Exporter & Aperçu** pour prévisualiser le document
5. Validez la génération

## Suivre la génération

La génération du PDF prend quelques instants :

1. Un message **Veuillez patienter…** s'affiche pendant le traitement
2. Une fois terminé, le message **Le fichier a été généré avec succès** apparaît
3. Téléchargez le fichier ou fermez la fenêtre

## Retrouver le bon de commande

Le PDF est enregistré dans l'onglet **Fichiers** du projet, dans le dossier **Exports**.

Consultez [Fichiers](/projet/fichiers) pour y accéder ultérieurement.

## En cas d'échec

Si la génération échoue :

1. Un message **La génération du fichier a échoué** s'affiche
2. Cliquez sur **Réessayer**
3. Si le problème persiste, rafraîchissez la page et relancez l'export

:::info
Si le lien de téléchargement a expiré, retournez dans **Fichiers** du projet pour télécharger le document depuis le dossier Exports.
:::
