# Mode liste

Le **mode liste** affiche les produits et prestations en lignes compactes, avec les prix toujours visibles, pour chiffrer et comparer rapidement.

## Activer le mode liste

1. Ouvrez la liste **Produits** de votre projet
2. Cliquez sur l’icône d’options d’affichage (réglages) dans la barre d’actions
3. Sous **Affichage**, choisissez **Liste**

Pour revenir à la vue cartes, choisissez **Grille**.

:::tip
Le choix grille / liste est mémorisé pour vos prochaines visites.
:::

## Ce que montre le mode liste

En mode liste :

- chaque ligne affiche le prix du produit ou de la prestation
- le **total** du projet (ou de la sélection / des filtres actifs) apparaît dans la barre d’actions
- le total de chaque **zone** ou **lot** s’affiche à droite du nom du groupe

### Modifier un prix depuis la liste

Cliquez sur le prix d’une ligne pour ouvrir le détail (prix unitaire, quantité, marge, taxes) et enregistrer sans quitter la liste. Vous pouvez aussi modifier le titre et le statut directement sur la ligne.

### Découpage des totaux

Cliquez sur le total dans la barre d’actions pour ouvrir le découpage des montants :

- sélection en cours
- filtres appliqués
- projet global

Pour chaque niveau : marge, HT et TTC. La part des prestations est indiquée quand elle existe.

## Mode grille

En **Grille**, les cartes restent centrées sur les images. Les prix ne s’affichent pas dans la grille côté agence : passez en **Liste** pour les voir et les éditer.

La taille des images reste réglable dans le menu d’affichage lorsqu’on est en grille.

## Côté client

Sur le [portail client](/portail-client/vue-ensemble), l’affichage reste en grille. Si le partage des prix est activé, le client active **Afficher les prix** dans le menu d’affichage pour voir les montants sur les cartes et le total dans la barre d’actions.
