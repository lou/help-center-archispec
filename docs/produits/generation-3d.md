# Modèles 3D

Créez des modèles 3D interactifs pour vos produits : générez-les par intelligence artificielle à partir d'une photo, ou importez un fichier existant.

## Prérequis

- Au moins **1 crédit 3D** disponible pour la génération IA (voir [Abonnement et limites](/facturation/abonnement-et-limites))
- Au moins **une image** sur la fiche produit pour la génération IA
- Abonnement non résilié

## Accéder aux modèles 3D

1. Ouvrez la fiche d'un produit (le panneau latéral s'ouvre à droite)
2. Cliquez sur l'onglet **3D**

Les produits avec un modèle 3D affichent un badge **3D** dans la liste.

## Générer un modèle

1. Dans l'onglet **3D**, sélectionnez l'image à utiliser comme base
2. Cliquez sur **Générer le modèle 3D**
3. Attendez la fin du traitement (quelques minutes)

Un crédit est débité au lancement de la génération. Une notification vous indique quand le modèle est prêt — vous pouvez continuer à travailler pendant le traitement.

## Importer un modèle

Pour utiliser un fichier 3D existant :

1. Dans l'onglet **3D**, cliquez sur **Importer un fichier 3D**
2. Sélectionnez un fichier (GLB, OBJ, FBX, SKP, STL, etc.)
3. Attendez la fin de l'import

L'import ne consomme pas de crédit 3D.

## Historique des modèles

Un produit peut avoir **plusieurs** modèles 3D. Le panneau **3D** liste toutes les versions :

- Le modèle **actif** s'affiche dans le viewer interactif
- Les modèles précédents (générations ou imports antérieurs) restent accessibles dans la liste
- Sélectionnez un modèle pour le prévisualiser ou le définir comme modèle actif

## Suivre l'avancement

Pendant une génération, un message **Nous générons le modèle 3D. Cela peut prendre quelques minutes.** s'affiche, accompagné d'une notification en arrière-plan.

L'interface se met à jour automatiquement lorsque le modèle est prêt.

## Consulter et télécharger

Une fois le modèle disponible :

1. Le viewer 3D interactif s'affiche dans l'onglet **3D**
2. Cliquez sur **Télécharger le modèle 3D** pour récupérer le fichier GLB
3. Le modèle est également accessible dans les **Fichiers** du produit

## Filtrer les produits avec 3D

Dans la liste des produits, ouvrez les filtres et activez **Produits avec 3D** pour n'afficher que les fiches disposant d'un modèle.

## Choisir la bonne image

Pour un meilleur résultat de génération IA :

- Privilégiez une photo nette du produit seul
- Évitez les images avec trop d'éléments d'arrière-plan
- Un angle légèrement en plongée donne souvent de bons résultats

## Regénérer un modèle

Si le résultat ne vous convient pas :

1. Cliquez sur l'option pour **retenter la génération**
2. Sélectionnez une autre image si besoin
3. Confirmez — cela consomme **1 crédit supplémentaire**

Le modèle précédent reste accessible dans l'historique.

## Crédits 3D

| Forfait | Crédits |
|---------|---------|
| Gratuit | 10 crédits à vie |
| Payant | 10 crédits par mois (renouvelés chaque mois) |

Le nombre de crédits restants est affiché sur la page **Facturation** et dans l'onglet **3D**.

## Côté client

Les clients voient une indication 3D sur les produits concernés, mais **ne peuvent pas générer, importer ni visualiser** les modèles 3D. Ces actions sont réservées à l'équipe de l'agence.

## Problèmes courants

| Message | Solution |
|---------|----------|
| Vous n'avez pas assez de crédits | Consultez [Abonnement et limites](/facturation/abonnement-et-limites) |
| Veuillez téléverser au moins une image | Ajoutez une image au produit avant de générer |
| Échec de la génération | Réessayez avec une autre image ou plus tard |
| Impossible d'importer le fichier | Vérifiez le format (GLB, OBJ, FBX, SKP, STL…) |
| La génération n'est pas disponible | Service temporairement indisponible — réessayez plus tard |

Pour placer ces modèles dans SketchUp (ou renvoyer une sélection SketchUp vers la fiche), voir l'[extension SketchUp](/sketchup/utilisation).

Pour plus de pistes, consultez la [FAQ](/faq).
