# Questions fréquentes

Réponses aux problèmes les plus courants sur Archispec.

## Compte et connexion

### Je n'arrive pas à me connecter

1. Vérifiez que votre email est correct
2. Si vous venez de vous inscrire, confirmez votre adresse via l'email de vérification
3. Utilisez la fonction de réinitialisation du mot de passe si nécessaire

### Je dois accepter les conditions d'utilisation

Lors de votre première connexion, vous devez accepter les conditions générales pour accéder à l'application.

### Mon client ne peut pas accéder au projet

1. Vérifiez que l'invitation a bien été envoyée (voir [Partage client](/projet/partage-client))
2. Demandez-lui de vérifier ses spams
3. Renvoyez l'invitation depuis les paramètres **Client** du projet

## Abonnement et limites

### Je ne peux plus ajouter de produits

Vous avez atteint la limite de **20 produits gratuits**. Abonnez-vous pour débloquer la création illimitée.

Consultez [Abonnement et limites](/facturation/abonnement-et-limites).

### Je ne peux pas inviter de membres

Votre abonnement a atteint la limite de sièges. Ajoutez une place depuis **Facturation** > **Gérer l'abonnement**.

### Un non-administrateur ne peut pas gérer la facturation

Seuls les administrateurs et propriétaires de l'agence peuvent accéder à la page **Facturation**. Les autres membres sont redirigés vers la gestion des membres.

## Exports

### L'export a échoué

1. Cliquez sur **Réessayer**
2. Vérifiez que des produits sont bien sélectionnés
3. Rafraîchissez la page et relancez l'export

### Je ne trouve pas mon fichier exporté

Les exports (carnet PDF, feuille de calcul, bon de commande) sont enregistrés dans l'onglet **Fichiers** du projet, dossier **Exports**.

Consultez [Fichiers](/projet/fichiers).

### Le lien de téléchargement ne fonctionne plus

Les liens de téléchargement expirent après un certain temps. Retournez dans **Fichiers** > dossier **Exports** pour télécharger le document.

## Génération 3D

### Je n'ai plus de crédits 3D

- **Forfait gratuit** : 10 crédits à vie — abonnez-vous pour obtenir 10 crédits par mois
- **Forfait payant** : les crédits se renouvellent chaque mois calendaire

Consultez [Générer un modèle 3D](/produits/generation-3d).

### La génération 3D échoue

1. Vérifiez que le produit a au moins une image
2. Essayez avec une autre image (produit seul, fond neutre)
3. Réessayez plus tard si le service est temporairement indisponible

### Le modèle 3D ne me convient pas

Vous pouvez regénérer avec une autre image. Chaque nouvelle tentative consomme 1 crédit supplémentaire. L'ancien modèle reste dans les fichiers du produit.

## Extension navigateur

### L'extension ne fonctionne pas sur mon navigateur

L'extension est compatible avec Chrome, Edge, Brave et Opera (navigateurs Chromium).

Consultez [Installation](/extension/installation).

### L'extension ne détecte pas le produit

1. Assurez-vous d'être sur une **page de détail produit** (pas une liste)
2. Rechargez la page et rouvrez l'extension
3. Complétez les champs manuellement si le site bloque l'extraction

### L'extension affiche « Non autorisé »

1. Connectez-vous sur [archispec.fr](https://archispec.fr)
2. Vérifiez que votre email est confirmé
3. Vérifiez que vous avez les droits pour créer des produits dans l'agence

Consultez [Utilisation de l'extension](/extension/utilisation).

## Extension SketchUp

### L'extension ne s'installe pas

Vérifiez que vous êtes sur **SketchUp Desktop 2025+**, puis réinstallez le `.rbz` via Extension Manager. Voir [Installation](/sketchup/installation).

### Impossible de placer un modèle 3D

Le produit doit avoir un modèle 3D (généré, importé ou lié). Vérifiez aussi que vous êtes membre du projet. Voir [Utilisation](/sketchup/utilisation).

### Comment publier la scène 3D du projet ?

Onglet **3D** du panneau SketchUp → **Publier** (nouvelle version ou remplacement). Voir [Scène 3D](/projet/scene-3d) et [Utilisation](/sketchup/utilisation).

### Comment mettre à jour l'extension ?

Une bannière apparaît dans le panneau quand une version plus récente est disponible. Sinon, retéléchargez depuis [archispec.fr/sketchup](https://archispec.fr/sketchup).

## Budget et prestations

### Je ne vois pas l'onglet Budget

L’onglet **Budget** est réservé aux **administrateurs** et **propriétaires** du projet. Les associés n’y ont pas accès.

Consultez [Budget](/projet/budget).

### Comment ajouter une pose ou des honoraires ?

Créez une [**prestation**](/produits/prestations) via **Ajouter** → **Prestation**, ou depuis l’onglet Budget. Une prestation peut être un montant fixe ou un pourcentage d’enveloppe.

### Où suivre les commandes et livraisons ?

Ouvrez la page **Achats** dans la navigation principale. Voir [Achats et suivi](/produits/achats-et-suivi).

## Portail client

### Le client ne voit pas certains produits

Seuls les produits au statut **Proposé** (ou au-delà) sont visibles. Passez le produit en **Proposé** depuis la fiche produit. Même logique pour les prestations visibles.

### Où voir les prix des produits ?

Côté agence, passez en [**mode liste**](/produits/mode-liste) depuis le menu d’options d’affichage de la liste Produits. Les prix et totaux s’affichent alors sur chaque ligne.

### Le client ne voit pas les prix

1. Activez le partage des prix dans les [paramètres de partage](/projet/parametres-partage) du projet
2. Sur le portail client, activez **Afficher les prix** dans le menu d’options d’affichage

### Le client ne voit pas l'onglet Avancement

Le planning doit être **activé sur le projet** (Paramètres → Modifier → Planning) et le partage **Espace client** doit être activé dans le menu **Partager** de l'onglet **Planning**.

Consultez [Planning](/projet/planning) et [Vue d'ensemble du portail client](/portail-client/vue-ensemble).

### Comment partager le planning hors Archispec ?

Créez un **lien externe** protégé par mot de passe depuis **Planning** → **Partager** → **Gérer les liens**. Voir [Planning](/projet/planning#liens-externes-lecture-seule).

## Fichiers et annotations

### Je ne peux pas annoter un fichier

Les annotations sont disponibles uniquement sur les **images** et les **PDF**, en ouvrant la prévisualisation du fichier. Les autres formats (vidéo, audio, etc.) ne sont pas annotables.

Consultez [Annotations](/projet/annotations).

### Mon client ne voit pas les annotations

Le fichier doit être rendu visible pour le client (icône œil). Une fois le fichier visible, le client voit les annotations et peut y répondre. Si une nouvelle version a suspendu les annotations précédentes, ouvrez l’ancienne version pour les consulter.

### Comment publier une nouvelle version d’un fichier ?

Ouvrez le fichier → **Proposer une nouvelle version**. Voir [Fichiers](/projet/fichiers#versions-dun-fichier).

### L'onglet Planning n'apparaît pas

Ouvrez **Paramètres** du projet → **Modifier**, puis activez l'option **Planning**. Le planning se configure projet par projet.

Consultez [Planning](/projet/planning).

## Nouveautés

### Où voir les nouveautés produit ?

Dans l’application, ouvrez **Nouveautés** (icône cadeau) dans la navigation. Un indicateur signale les entrées non lues.
