# Créer votre compte

Ce guide vous accompagne de l'inscription à votre première connexion sur Archispec.

## S'inscrire

1. Rendez-vous sur [archispec.fr](https://archispec.fr)
2. Cliquez sur **S'inscrire**
3. Renseignez votre adresse email et votre mot de passe
4. Validez le formulaire

## Vérifier votre email

1. Consultez votre boîte mail
2. Ouvrez l'email de vérification envoyé par Archispec
3. Cliquez sur le lien de confirmation

Votre compte est activé une fois l'email vérifié.

## Accepter les conditions d'utilisation

Lors de votre première connexion, vous devrez accepter les conditions générales d'utilisation pour accéder à l'application.

## Se connecter

1. Rendez-vous sur [archispec.fr/signin](https://archispec.fr/signin)
2. Saisissez votre email et votre mot de passe
3. Cliquez sur **Se connecter**

## Étape suivante

Passez à [Configurer votre agence](/premiers-pas/configurer-agence) pour créer ou rejoindre l'espace de travail de votre équipe.
