# Configurer votre agence

Votre agence est l'espace de travail partagé de votre équipe : projets, catalogue et membres y sont regroupés.

## Créer une agence

Si vous venez de vous inscrire :

1. Saisissez le nom de votre agence
2. Validez la création

Votre agence est créée et vous en êtes le propriétaire.

## Rejoindre une agence existante

Si un collègue vous a invité :

1. Ouvrez l'email d'invitation
2. Cliquez sur le lien pour rejoindre l'agence
3. Connectez-vous ou créez un compte si nécessaire

## Inviter des collègues

1. Dans le menu principal, cliquez sur le nom de votre agence
2. Accédez à **Membres**
3. Cliquez sur **Inviter un nouveau membre**
4. Saisissez l'email et choisissez le rôle
5. Cliquez sur **Envoyer une invitation**

Pour le détail des rôles, consultez [Gestion des membres](/agence/gestion-membres) et [Rôles et permissions](/comprendre/roles-permissions).

## Paramétrer l'agence

Depuis le menu de l'agence, vous pouvez aussi :

- Gérer les [types de produits](/agence/types-produits)
- Constituer le répertoire des [entreprises](/agence/entreprises) intervenantes
- Gérer fabricants et fournisseurs
