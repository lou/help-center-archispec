# Créer un projet et ajouter un produit

Créez votre premier projet et ajoutez-y un produit pour démarrer votre spécification.

## Créer un projet

1. Dans le menu principal, cliquez sur **Projets**
2. Cliquez sur **Nouveau projet**
3. Renseignez le titre du projet (ex. « Rénovation Dupont »)
4. Validez la création

Vous êtes redirigé vers la page du projet.

## Configurer les sections (recommandé)

Les sections organisent vos produits par pièce ou par étage :

1. Accédez aux **Paramètres** du projet
2. Cliquez sur **Sections**
3. Ajoutez vos sections (ex. « Cuisine », « Salon »)

Consultez [Gestion des sections](/projet/gestion-sections) pour plus de détails.

## Ajouter votre premier produit

Choisissez l'une de ces méthodes :

### Créer un produit manuellement

1. Dans l'onglet **Produits**, cliquez sur **Nouveau produit**
2. Renseignez au minimum le **nom** du produit
3. Assignez une **section** si vous en avez créé
4. Cliquez sur **Sauvegarder**

### Depuis l'extension navigateur

1. Installez l'[extension Chrome](/extension/installation)
2. Naviguez sur la page d'un produit fournisseur
3. Ouvrez l'extension et vérifiez les informations extraites
4. Sélectionnez votre projet et cliquez sur **Ajouter**

### Depuis le catalogue

Si vous avez déjà des produits dans le catalogue :

1. Cliquez sur **Ajouter depuis la bibliothèque**
2. Sélectionnez les produits souhaités
3. Cliquez sur **Ajouter au projet**
