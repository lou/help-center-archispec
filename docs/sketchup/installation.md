# Installation de l'extension SketchUp

L'extension Archispec pour SketchUp Desktop connecte un modèle `.skp` à un projet Archispec : produits, modèles 3D, matières.

## Prérequis

- **SketchUp Desktop 2025** ou plus récent (import GLB natif)
- SketchUp for Desktop uniquement (pas SketchUp Web / iPad)
- Un [compte Archispec](https://archispec.fr) avec accès à un projet

## Télécharger

1. Ouvrez la [page SketchUp sur archispec.fr](https://archispec.fr/sketchup)
2. Cliquez sur **Télécharger l'extension** pour obtenir le fichier `.rbz`

Vous pouvez aussi utiliser l'URL de téléchargement stable :  
`https://archispec.fr/api/sketchup-extension/download` (redirection vers le fichier courant).

## Installer dans SketchUp

1. Dans SketchUp, ouvrez **Fenêtre → Extension Manager**
2. Cliquez sur **Install Extension**
3. Sélectionnez le fichier `.rbz` téléchargé
4. Redémarrez SketchUp si l'extension ne s'active pas immédiatement
5. Ouvrez **Extensions → Archispec → Open Panel**

L'extension apparaît aussi via la barre d'outils Archispec.

## Mettre à jour

Quand une nouvelle version est disponible, le panneau Archispec affiche une bannière de mise à jour. Vous pouvez :

- **Installer la mise à jour** depuis le panneau (téléchargement + installation automatiques)
- ou retélécharger le `.rbz` depuis [archispec.fr/sketchup](https://archispec.fr/sketchup)

:::info
L'extension packagée pointe vers la production (`https://archispec.fr`). Une installation depuis le dépôt git utilise l'environnement de développement local.
:::
