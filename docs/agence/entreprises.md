# Entreprises

Les **Entreprises** sont le répertoire des sociétés intervenantes de votre agence (entreprises de travaux, installateurs, etc.). Elles s'assignent comme intervenants sur les [lots](/projet/gestion-lots) d'un projet.

:::info
Une entreprise dans ce répertoire n'a **pas** de compte Archispec. Ce n'est pas un membre de l'équipe ni un client : c'est une fiche de référence pour organiser les lots.
:::

## Accéder aux entreprises

1. Dans le menu principal, cliquez sur le nom de votre agence
2. Cliquez sur **Entreprises**

Seuls les administrateurs et propriétaires de l'agence peuvent gérer cette liste.

## Ajouter une entreprise

1. Saisissez le nom dans le champ prévu
2. Cliquez sur **Ajouter**

Vous pouvez aussi créer une entreprise à la volée lorsque vous assignez l'intervenant d'un lot.

## Renommer ou supprimer

- Cliquez sur le nom pour le modifier en ligne
- Cliquez sur l'icône corbeille pour supprimer (après confirmation)
