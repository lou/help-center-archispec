# Types de produits

Les **Types** sont les catégories de produits de votre agence (mobilier, éclairage, sanitaire, etc.). Ils servent à classer les produits et à les [filtrer](/produits/filtres) dans les projets et le catalogue.

## Accéder aux types

1. Dans le menu principal, cliquez sur le nom de votre agence
2. Cliquez sur **Types**

Seuls les administrateurs et propriétaires de l'agence peuvent gérer cette liste.

## Ajouter un type

1. Saisissez le nom du type
2. Cliquez sur **Ajouter**

## Renommer ou supprimer

- Cliquez sur le nom pour le modifier en ligne
- Cliquez sur l'icône corbeille pour supprimer (après confirmation)

Un type utilisé sur des produits peut être retiré de la liste ; les produits concernés perdent ce rattachement.

## Utiliser les types

1. À la création ou modification d'un produit, sélectionnez un ou plusieurs types
2. Filtrez la liste des produits par type dans le projet ou le catalogue
3. En [modification en lot](/produits/selection), ajoutez des types à plusieurs produits d'un coup

:::tip
Harmonisez les noms de types dans toute l'agence pour que le filtrage reste cohérent d'un projet à l'autre.
:::
