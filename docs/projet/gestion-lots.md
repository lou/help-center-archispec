# Gestion des lots

Les lots regroupent les produits et les tâches de planning par corps de métier (plomberie, menuiserie, électricité, etc.). Chaque projet a sa propre liste de lots.

## Accéder aux lots

1. Ouvrez votre projet
2. Accédez aux **Paramètres**
3. Cliquez sur **Lots** dans le menu latéral

## Créer un lot

1. Cliquez sur **Ajouter**
2. Saisissez le nom du lot
3. Choisissez l'**intervenant** :
   - **Aucun intervenant** — aucun rattachement
   - **Client** — le lot est assuré par le client (option disponible si un client est invité sur le projet)
   - **Entreprise** — rattachez une [entreprise](/agence/entreprises) de votre agence (vous pouvez en créer une à la volée)
4. Validez la création

## Modifier ou supprimer un lot

1. Cliquez sur l'icône d'édition à droite du lot
2. Modifiez le nom ou l'intervenant
3. Enregistrez

Pour supprimer un lot, ouvrez l'édition puis confirmez la suppression. Les produits rattachés perdent leur lot.

## Importer des lots depuis un autre projet

Pour réutiliser la liste d'un projet existant :

1. Dans **Lots**, cliquez sur **Importer**
2. Sélectionnez le projet source
3. Validez

Les lots déjà présents (même nom) sont ignorés.

Vous pouvez aussi importer des lots à la **création d'un nouveau projet**.

## Utiliser les lots

- Sur un **produit** : rattachez un lot pour organiser et filtrer. Si un lot est choisi, vous pouvez préciser la [fourniture / pose](/produits/ajouter-produit#fourniture--pose).
- Sur le **planning** : créez des tâches à partir d'un lot pour structurer le calendrier.
- En **modification en lot** : changez le lot de plusieurs produits via [Sélectionner les produits](/produits/selection).

:::tip
Créez d'abord vos [entreprises](/agence/entreprises) au niveau agence si vous souhaitez les assigner comme intervenants sur les lots.
:::
