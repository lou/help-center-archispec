# Planning

La fonctionnalité Planning d'ArchiSpec vous aide à piloter un projet de manière visuelle, claire et collaborative. En un coup d'oeil, vous voyez les tâches en cours, les prochaines et les dépendances entre elles.

## À quoi sert le planning ?

- Visualiser tout le planning du projet sur une ligne de temps
- Suivre l'avancement de chaque tâche
- Ajuster rapidement les dates et l'ordre des tâches
- Anticiper les impacts grâce aux dépendances
- Partager une vue claire avec le client quand vous êtes prêt

## Lire le planning

Chaque ligne représente une tâche, avec :

- Sa période (date de début -> date de fin)
- Son niveau d'avancement
- Ses dépendances éventuelles

Vous pouvez basculer entre :

- **Vue Semaine** pour un pilotage détaillé
- **Vue Mois** pour une vision plus globale

## Naviguer rapidement

- Cliquez sur le **nom d'une tâche** pour aller directement à sa date de début
- Le planning se positionne automatiquement autour de la date du jour au chargement pour donner du contexte immédiat

## Éditer une tâche

Cliquez sur le **bloc d'une tâche** pour ouvrir le panneau d'édition.

Vous pouvez modifier :

- Le titre
- La date de début
- La durée
- L'avancement
- Les dépendances

## Gérer les dépendances

Quand une tâche dépend d'une autre, vous pouvez lier leur planning pour garder un enchaînement cohérent. Une flèche apparaît entre les tâches pour visualiser cette relation.

Bénéfice : si vous déplacez la tâche parente, vous comprenez immédiatement l'impact sur la suite du planning.

## Partage global au client

Quand votre planning est solide, activez le **partage global client**. Vous choisissez le bon moment pour partager une version propre, lisible et rassurante.

Le client voit clairement :

- Où en est le projet
- Ce qui arrive ensuite

De votre côté, vous gardez une gestion interne plus détaillée, avec la possibilité de contrôler aussi la visibilité tâche par tâche.

## En résumé

Le Planning vous permet de :

- Structurer le projet
- Suivre l'avancement en temps réel
- Anticiper les dépendances
- Communiquer plus clairement avec le client

C'est un outil de pilotage concret pour sécuriser les délais et fluidifier les échanges tout au long du projet.
