# Notifications

Restez informé des activités importantes dans vos projets grâce au centre de notifications et aux préférences personnalisables.

## Centre de notifications

1. Cliquez sur l'icône de notifications dans la barre de navigation
2. Consultez la liste des événements récents (changements de statut, messages, etc.)
3. Cliquez sur une notification pour accéder directement à l'élément concerné

## Configurer vos préférences

1. Accédez à vos **Paramètres** de compte
2. Ouvrez la section **Préférences de notification**
3. Pour chaque type d'événement, activez ou désactivez les canaux souhaités :
   - **Application** : notification dans le centre de notifications
   - **Email** : envoi d'un email

4. Cliquez sur **Sauvegarder**

:::info
Ces préférences s'appliquent par défaut à tous vos projets. Vous pouvez les modifier individuellement dans les paramètres de chaque projet.
:::

## Événements notifiables (équipe)

| Événement | Description |
|-----------|-------------|
| Statut modifié par un client | Un client change le statut d'un produit (aimé, validé, etc.) |
| Statut modifié par un associé | Un collègue met à jour le statut d'un produit |
| Message d'un associé | Un membre de l'équipe envoie un message dans le chat |
| Message d'un client | Un client vous contacte via le chat |

## Bonnes pratiques

- Activez les notifications **email** pour les messages clients si vous ne consultez pas Archispec en continu
- Activez les notifications **application** pour le suivi des validations produit au quotidien
- Vérifiez vos préférences lors de l'invitation d'un nouveau client sur un projet
