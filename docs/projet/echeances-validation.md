# Échéances de validation

Fixez une date limite pour que le client valide un ensemble de produits ou de prestations. Les échéances apparaissent sur le [planning](/projet/planning) et dans les vues **À valider** / **Achats**.

## Créer une échéance

Vous pouvez rattacher une échéance :

- à un **lot** (tous les produits / prestations du lot sans date propre)
- directement à un **produit** ou une **prestation**

### Depuis un lot

1. Ouvrez l’onglet **Lots**, ou le panneau du lot concerné
2. Ajoutez une **échéance de validation**
3. Renseignez la date **À valider avant le**
4. Optionnellement, donnez un **titre** (ex. « Carrelage sol RDC »)

### Depuis le planning

Les échéances de lot s’affichent aussi sur la timeline du planning. Vous pouvez les positionner par rapport au début du lot (le jour J, X jours avant ou après).

## Suivre les validations côté agence

1. Ouvrez **Achats** ou la vue de suivi des validations
2. Filtrez sur **Validation client**
3. Repérez les éléments **en retard**, à valider aujourd’hui ou à venir

Chaque produit ou prestation proposé avec une date limite apparaît dans ces listes.

## Côté client

Le client dispose d’une file **À valider** / **Choix à valider** qui regroupe les éléments proposés, avec ou sans échéance. Les éléments en retard sont mis en évidence.

Voir [Valider des produits](/portail-client/validation-produits).

## Rappels

Dans les [préférences de notification](/projet/notifications), activez les **rappels de validation** pour recevoir chaque matin un résumé des validations en retard, et un rappel la veille de l’échéance.

## Supprimer une échéance

La suppression d’une échéance ne supprime pas les produits : ils perdent uniquement cette date limite.
