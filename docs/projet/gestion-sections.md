# Gestion des sections

Les sections permettent d'organiser votre projet par pièces, étages, ou toute autre division logique.

## Créer une section

1. Accédez aux **Paramètres** du projet
2. Cliquez sur **Sections** dans le menu latéral
3. Cliquez sur **Ajouter une section**
4. Entrez le nom de la section (ex. « Rez-de-chaussée », « Cuisine », « Chambre 1 »)
5. Optionnellement, ajoutez une description
6. Cliquez sur **Créer**

## Modifier une section

1. Accédez aux **Paramètres** du projet
2. Cliquez sur **Sections**
3. Cliquez sur la section que vous souhaitez modifier
4. Modifiez le nom ou la description
5. Cliquez sur **Enregistrer**

## Réorganiser les sections

Vous pouvez réorganiser l'ordre des sections par glisser-déposer :

1. Accédez aux **Paramètres** du projet
2. Cliquez sur **Sections**
3. Cliquez et maintenez sur une section
4. Glissez-la à la position souhaitée
5. Relâchez pour valider

## Supprimer une section

1. Accédez aux **Paramètres** du projet
2. Cliquez sur **Sections**
3. Cliquez sur l'**icône corbeille** à droite de la section
4. Confirmez l'action

**Attention** : Si la section contient des produits, ils seront tous désassignés de la section et apparaîtront « Sans section ».
