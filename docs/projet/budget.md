# Budget

L’onglet **Budget** suit la consommation de votre enveloppe projet à partir des produits et [prestations](/produits/prestations) chiffrés. Les totaux se mettent à jour dès qu’un prix change.

## Accéder au budget

1. Ouvrez votre projet
2. Cliquez sur l’onglet **Budget**

:::info
L’onglet **Budget** est visible pour les **administrateurs** et **propriétaires** du projet. Les associés n’y ont pas accès.
:::

## Enveloppe globale

Définissez le montant alloué au projet :

1. Dans **Budget**, cliquez sur **Définir une enveloppe globale** (ou sur le montant déjà saisi)
2. Saisissez le montant
3. Validez

Le **coût final estimé** agrège les produits et prestations retenus. L’**écart à l’enveloppe** (ou le **dépassement**) compare ce coût à l’enveloppe.

Vous pouvez basculer l’affichage entre **HT** et **TTC** via le contrôle en haut à droite.

## Lecture du budget

La jauge et les indicateurs décomposent le montant :

| Indicateur | Signification |
|------------|---------------|
| **Validé** | Validé par le client |
| **À valider** | Proposé (ou aimé), en attente de validation client |
| **En préparation** | Brouillons encore inclus dans le prévisionnel |
| **Marge** | Marge calculée sur les postes concernés |
| **Sélections** / **Écart** | Montant projeté, ou reste / dépassement par rapport à l’enveloppe |

Si des postes attendus n’ont pas encore de prix, un message signale un **prévisionnel incomplet**.

## Budget par zone ou par lot

Sous l’enveloppe globale, lisez le budget par **zone** ou par **lot** :

1. Choisissez l’axe (**Zone** ou **Poste** / lot)
2. Cliquez une ligne pour ouvrir le détail des produits et prestations qui la composent

Les enveloppes se définissent uniquement sur les **lots** (pas sur les zones). Sur l’axe lot, saisissez une enveloppe sur une ligne si besoin.

Les alertes **À surveiller** signalent les dépassements, les enveloppes de lot mal réparties, ou les montants sans zone / sans lot.

Les graphiques de répartition visualisent la part de chaque zone ou lot dans le total.

:::tip
Vous pouvez aussi définir une enveloppe sur un lot depuis l’onglet **Lots**.
:::

## Ajouter une prestation depuis le budget

Depuis l’onglet **Budget**, utilisez **Ajouter une prestation** pour créer une ligne de pose, main-d’œuvre ou honoraires sans passer par un produit. Voir [Prestations](/produits/prestations).

## En résumé

Le Budget vous permet de :

- Fixer une enveloppe globale et par lot
- Suivre en temps réel le coût estimé, le montant validé et le montant qu’il reste à valider
- Repérer les dépassements avant le rendez-vous client
- Relier chaque montant aux produits et prestations concernés
