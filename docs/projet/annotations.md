# Annotations

Commentez un point précis sur un plan, une image ou un PDF, directement dans la prévisualisation du fichier. Chaque annotation ouvre un fil de discussion partagé avec l'équipe et les clients du projet.

## Fichiers concernés

Les annotations sont disponibles lorsque vous ouvrez la prévisualisation d'une **image** ou d'un **PDF** :

- dans l'onglet **Fichiers** du projet
- dans l'onglet **Fichiers** d'un produit

Les autres types de fichiers (vidéo, audio, etc.) se prévisualisent sans annotations.

## Créer une annotation

1. Ouvrez le fichier image ou PDF depuis **Fichiers**
2. Cliquez sur l'endroit du document à commenter (le curseur devient une croix)
3. Saisissez votre commentaire dans la fenêtre qui s'ouvre
4. Validez pour créer l'annotation

Un marqueur numéroté apparaît à l'emplacement choisi. Sur un PDF multipage, l'annotation est rattachée à la **page** courante.

:::info
L'annotation n'est créée qu'après l'envoi du premier commentaire. Fermer la fenêtre sans écrire n'enregistre rien.
:::

## Répondre à une annotation

1. Cliquez sur un marqueur sur le document, ou sélectionnez l'annotation dans le panneau latéral
2. Saisissez votre réponse
3. Envoyez le message

Vous pouvez **mentionner** un membre ou un client avec `@` pour l'alerter directement.

Chaque auteur peut modifier ses propres commentaires après envoi.

## Résoudre ou rouvrir

Lorsque le point est traité :

1. Ouvrez l'annotation
2. Cliquez sur l'icône de résolution (coche)

L'annotation est marquée comme résolue. Vous pouvez la rouvrir à tout moment avec l'icône correspondante.

## Afficher, masquer et naviguer

Dans la prévisualisation :

- **Voir** : affiche ou masque les marqueurs sur le document
- **Montrer les résolues** : inclut ou exclut les annotations résolues de la liste et du document
- Le panneau **Annotations** liste tous les fils du fichier ; cliquez une entrée pour ouvrir le fil et centrer le marqueur
- Sur un PDF, utilisez les miniatures de pages pour changer de page
- Zoomez avec les contrôles `+` / `-` pour placer ou lire une annotation plus précisément

## Supprimer une annotation

1. Ouvrez l'annotation
2. Cliquez sur l'icône de suppression
3. Confirmez

La suppression retire l'annotation et **tous** ses commentaires. Cette action est irréversible.

## Notifications

Les membres de l'équipe sont notifiés lorsqu'un commentaire est ajouté, ou lorsqu'une annotation est résolue ou rouverte (selon leurs préférences).

Les mentions `@` notifient la personne mentionnée, y compris un client.

Pour activer ou désactiver ces alertes (application et email), consultez [Notifications](/projet/notifications).

## Côté client

Les clients peuvent annoter les fichiers que vous avez rendus visibles. Ils voient les mêmes marqueurs et fils de discussion que l'équipe sur ces documents.

:::tip
Utilisez les annotations pour centraliser les retours sur un plan ou une fiche technique, plutôt que de multiplier les échanges dans le chat général.
:::
