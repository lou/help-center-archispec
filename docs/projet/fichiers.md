# Fichiers

Centralisez plans, fiches techniques, visuels et exports dans l'onglet **Fichiers** de votre projet.

## Accéder aux fichiers

1. Ouvrez votre projet
2. Cliquez sur l'onglet **Fichiers**

Vous voyez l'arborescence des dossiers et la liste des fichiers du dossier courant.

## Ajouter un fichier

1. Dans l'onglet **Fichiers**, cliquez sur **Ajouter un fichier**
2. Sélectionnez le fichier sur votre ordinateur
3. Attendez la fin du téléchargement

Le fichier apparaît dans le dossier ouvert.

## Créer un dossier

1. Cliquez sur **Nouveau dossier**
2. Saisissez le nom du dossier
3. Validez la création

Vous pouvez naviguer dans les sous-dossiers via le fil d'Ariane en haut de la page.

## Partager un fichier avec le client

Par défaut, les fichiers ne sont pas visibles par le client.

1. Repérez l'icône en forme d'œil à droite du fichier
2. Cliquez pour basculer la visibilité :
   - Œil ouvert : le fichier est visible par le client
   - Œil barré : le fichier est masqué pour le client

:::info
Pour plus de détails sur le partage client, consultez [Partage client](/projet/partage-client).
:::

## Annoter une image ou un PDF

Sur une image ou un PDF, ouvrez la prévisualisation puis cliquez sur le document pour placer un commentaire ponctuel. L'équipe et les clients peuvent répondre dans le même fil, résoudre le point ou mentionner un membre avec `@`.

Consultez [Annotations](/projet/annotations) pour le détail.

## Prévisualiser audio et vidéo

Les fichiers audio et vidéo s'ouvrent dans la même prévisualisation, avec un lecteur intégré (lecture, pause, volume). Ils ne sont pas annotables.

Comme pour les autres fichiers, le client ne voit que ceux rendus visibles (icône œil).

## Fichiers liés aux produits

Chaque produit dispose de son propre espace fichiers :

1. Ouvrez un produit
2. Accédez à l'onglet **Fichiers** de la fiche produit

Les documents attachés à un produit (fiches techniques, visuels, etc.) sont regroupés dans ce dossier.

## Dossiers d'export

Lorsque vous exportez des produits (carnet de détails PDF ou feuille de calcul Excel), Archispec génère les fichiers dans des dossiers dédiés du projet.

1. Consultez la section [Sélectionner les produits](/produits/selection) pour lancer un export
2. Une fois la génération terminée, retrouvez le fichier dans l'onglet **Fichiers** du projet

## Côté client

Les clients invités au projet peuvent consulter et télécharger uniquement les fichiers que vous avez rendus visibles. Ils ne peuvent pas ajouter, modifier ni supprimer de fichiers. En revanche, ils peuvent [annoter](/projet/annotations) les images et PDF visibles.
