Select products

Select one or more products to perform bulk actions.

Select products​

Select one product​

  1. Click the checkbox to the left of the product
  2. The product is selected (marked with a check)

Select multiple products​

  1. Click the checkboxes of each desired product
  2. All selected products are highlighted

Select all visible products​

  1. Click the "Select all" checkbox in the action bar above the list
  2. All currently visible products are selected

Note: Only visible products (after filters) are selected, not all products in the project.

Visual indicators​

Selected products are highlighted with:

  • A check in the checkbox
  • A slightly colored background
  • A counter in the action bar showing the number of selected products

Actions on selected products​

Once products are selected, buttons appear in the action bar.

Actions​

The "Actions" button lets you perform group actions on selected products.

Bulk edit​

  1. Select multiple products
  2. Click Actions > Update
  3. Choose the fields to modify:
    • Status
    • Section
    • Lot
    • Types (add)
  4. Enter the new values
  5. Click Save

Archive​

  1. Select the products to archive
  2. Click Archive
  3. Confirm the action

Duplicate​

  1. Select the products to duplicate
  2. Click Duplicate
  3. Select one or multiple destination sections
  4. Click Duplicate

Duplication runs in the background. A notification tells you when the copies are ready.

Export​

The "Export" button lets you export products in different formats.

Export to PDF​

  1. Select the products to export
  2. Click Export > Detail booklet
  3. Choose the fields to export
  4. Click Export
  5. The PDF file is generated
  6. You can download the file in the project's Files section

Export to spreadsheet​

  1. Select the products to export
  2. Click Export > Spreadsheet
  3. Choose the fields to export
  4. Click Export
  5. The Excel file is generated
  6. You can download the file in the project's Files section

Export a purchase order​

To generate a supplier order PDF with purchase order number and addresses, see Purchase order.
