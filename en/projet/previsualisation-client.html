Client preview

Client preview lets you see exactly how the interface appears to the client. In preview mode, all actions are disabled, eliminating any risk of accidental changes.

Enable/disable client preview​

  1. Go to your project page
  2. Click the eye icon to the right of the project name
  3. You are now in preview mode — an orange banner at the top of the page confirms this
  4. To exit preview mode, click the X on the right of the orange banner

Displayed information​

  • Product name
  • Description
  • Images
  • Price (depending on project settings)
  • Web link (depending on project settings)
  • Files shared with the client (depending on project settings)
