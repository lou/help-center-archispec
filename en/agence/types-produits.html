Product types

Types are your agency's product categories (furniture, lighting, sanitary, etc.). They classify products and power filters in projects and the catalog.

Access types​

  1. In the main menu, click your agency name
  2. Click Types

Only agency administrators and owners can manage this list.

Add a type​

  1. Enter the type name
  2. Click Add

Rename or delete​

  • Click the name to edit it inline
  • Click the trash icon to delete (after confirmation)

A type used on products can be removed from the list; those products lose that association.

Using types​

  1. When creating or editing a product, select one or more types
  2. Filter the product list by type in a project or the catalog
  3. In bulk edit, add types to several products at once
tip

Keep type names consistent across the agency so filtering stays clear from one project to another.
