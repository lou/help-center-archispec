Installing the extension

The Archispec extension lets you quickly extract products from any website and add them to your projects.

Installation​

  1. Go to the Chrome Web Store - Archispec Extension
  2. Click Add to Chrome
  3. Confirm the installation by clicking Add extension
  4. Click the puzzle icon in the toolbar
  5. Click the pin icon for the Archispec extension

🎉 The extension is now installed and the Archispec icon appears in the Chrome toolbar.

Supported browsers​

The extension is available for:

  • Google Chrome
  • Microsoft Edge
  • Brave
  • Opera
  • All Chromium-based browsers

Update the extension​

The extension updates automatically if installed from the Chrome Web Store.
