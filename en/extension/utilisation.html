Using the extension

Learn how to use the Archispec extension to extract and add products quickly from any website.

Prerequisites​

  • Extension installed — see Installation
  • Signed in to your Archispec account in the browser

Extract a product​

On a product page​

  1. Navigate to a website containing a product (supplier site, e-commerce, etc.)
  2. Make sure you are on the product detail page
  3. Click the Archispec extension icon in the toolbar
  4. The extension automatically analyzes the page and extracts:
    • Product name
    • Price
    • Description
    • Images
    • Reference
    • Manufacturer
    • Supplier

Review and complete the information​

  1. Review the pre-filled fields in the extension panel
  2. Correct values if needed (price, quantity, description)
  3. Add or remove images via the drag-and-drop area

Save the product​

To a project​

  1. Select the destination project from the dropdown
  2. Once the project is selected, optionally fill in:
    • Trade (trade category)
    • Area (room or space)
    • Product type
  3. Click Add

The product is created in the project. A link to the product page is displayed for direct access.

To the catalog​

  1. Leave the Project field empty
  2. Click Add

The product is saved to your agency catalog. You can reuse it in your projects later.

See Manage the catalog for more details.

Troubleshooting​

The extension doesn't extract information​

  • Make sure you are on a product detail page (not a list or homepage)
  • Reload the page and reopen the extension
  • Some sites protect their data: fill in the fields manually

I'm not signed in​

  1. Click the sign-in link in the extension panel
  2. Sign in at archispec.fr
  3. Return to the product page and reopen the extension

The project doesn't appear in the list​

  • Check that you are a member of the project in Archispec
  • Refresh the extension panel
info

The extension remembers the last selected project to speed up consecutive additions.
