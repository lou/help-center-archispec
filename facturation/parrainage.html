Parrainage

Le programme de parrainage permet à votre agence et aux agences que vous parrainez de bénéficier de crédits sur l'abonnement.

Accéder au parrainage​

  1. Dans le menu principal, cliquez sur le nom de votre agence
  2. Accédez à Parrainage
info

Le parrainage est disponible pour les agences disposant d'un abonnement actif avec un moyen de paiement configuré.

Comment ça fonctionne​

  1. Partagez votre lien de parrainage ou votre code avec une autre agence
  2. L'agence parrainée s'inscrit et souscrit à un abonnement payant
  3. Chacun reçoit 60 € de crédit appliqué automatiquement sur la facturation Stripe
BénéficiaireCrédit
Vous (parrain)60 €
L'agence parrainée60 €

Les crédits sont appliqués sur les prochaines factures via Stripe.

Partager votre code​

Sur la page Parrainage :

  1. Copiez le lien de parrainage ou le code
  2. Envoyez-le à une autre agence (par email, message, etc.)

L'agence parrainée peut aussi saisir votre code lors de l'inscription.

Conditions​

  • Le parrain doit avoir un abonnement actif avec un moyen de paiement configuré
  • Le crédit du parrain est attribué lors de la première facture payée du filleul
  • Un code de parrainage invalide ou expiré ne pourra pas être utilisé

Problèmes courants​

MessageCause probable
Code de parrainage invalideCode incorrect ou expiré
Le parrain n'est pas éligibleLe parrain n'a pas encore configuré de moyen de paiement
