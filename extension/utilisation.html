Utilisation de l'extension

Apprenez à utiliser l'extension Archispec pour extraire et ajouter des produits rapidement depuis n'importe quel site web.

Prérequis​

  • Extension installée — voir Installation
  • Être connecté à votre compte Archispec dans le navigateur

Extraire un produit​

Sur une page de produit​

  1. Naviguez sur un site web contenant un produit (site fournisseur, e-commerce, etc.)
  2. Assurez-vous d'être sur la page de détail du produit
  3. Cliquez sur l'icône de l'extension Archispec dans la barre d'outils
  4. L'extension analyse automatiquement la page et extrait les informations :
    • Nom du produit
    • Prix
    • Description
    • Images
    • Référence
    • Fabricant
    • Fournisseur

Vérifier et compléter les informations​

  1. Parcourez les champs préremplis dans le panneau de l'extension
  2. Corrigez les valeurs si nécessaire (prix, quantité, description)
  3. Ajoutez ou retirez des images via la zone de glisser-déposer

Enregistrer le produit​

Dans un projet​

  1. Sélectionnez le projet de destination dans la liste déroulante
  2. Une fois le projet choisi, renseignez optionnellement :
    • Lot (corps de métier)
    • Section (pièce ou espace)
    • Type de produit
  3. Cliquez sur Ajouter

Le produit est créé dans le projet. Un lien vers la fiche produit s'affiche pour y accéder directement.

Dans le catalogue​

  1. Laissez le champ Projet vide
  2. Cliquez sur Ajouter

Le produit est enregistré dans le catalogue de votre agence. Vous pourrez le réutiliser dans vos projets ultérieurement.

Consultez Catalogue pour plus de détails.

Dépannage​

L'extension n'extrait pas les informations​

  • Vérifiez que vous êtes bien sur une page de détail produit (et non une liste ou une page d'accueil)
  • Rechargez la page et rouvrez l'extension
  • Certains sites protègent leurs données : complétez les champs manuellement

Je ne suis pas connecté​

  1. Cliquez sur le lien de connexion dans le panneau de l'extension
  2. Connectez-vous sur archispec.fr
  3. Revenez sur la page produit et rouvrez l'extension

Le projet n'apparaît pas dans la liste​

  • Vérifiez que vous êtes membre du projet dans Archispec
  • Actualisez le panneau de l'extension
info

L'extension mémorise le dernier projet sélectionné pour accélérer vos ajouts successifs.
